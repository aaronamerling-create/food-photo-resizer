# Food Photo Resizer

Batch tool for food test photos. Drop in full-resolution photos named after the food and it writes four versions of each:

- `Name_Full` – untouched original (reference)
- `Name_2MP` – about 2,000,000 pixels
- `Name_720p` – 720 px on the short side
- `Name_VGA` – 480 px on the short side

Aspect ratio is kept, nothing is cropped or upscaled. Everything runs in your browser; photos are never uploaded anywhere.

**Use it in Chrome or Edge** so it can save straight to a folder you pick. Other browsers download a .zip instead.

When uploading results to Google Photos, use "Original quality" so the files aren't recompressed.
